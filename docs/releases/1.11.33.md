# TumoCompanion 1.11.33 (286)

- Protect managed **USB CD-ROM** (`usb_cdrom`) and the native archive/favorites writer (`archive_favorites`, including its data/plugin family) from default Community Pack replacement. Existing explicit user protection overrides remain user choices.
- Add verified, bounded, read-only **Field Reports** for Sensor Watch, Power Journal, Tumo UHF Inventory and Varta Inspector. Browse saved sessions, inspect graphs/values and export verified CSV snapshots through Files/share. Malformed/oversized/path-unsafe reports fail closed.
- Report reading does not write to Flipper, start background sampling, invent object associations or create an offline history cache.

Recommended order: refresh Feather/install **1.11.33 (286)**, then install
**Tumoflip Dev009-034** with native resources, then refresh **FW Packages
Dev031 → Base** for USB CD-ROM. Older firmware/package installations remain
separate choices; the app does not flash devices automatically. Reports require
the corresponding FAP to have saved a supported CSV session first.

No BLE connection-state/Home-console redesign, pairing reset, SD cleanup or
user-data migration is introduced. This is not proof of an idle-OOM or BLE
stability fix. Source changes are from merged PR240; publication still requires
fresh build/test/IPA verification and a separate public Feather metadata check.

The IPA is unsigned/ad-hoc packaged for re-signing with the user's certificate
in Feather. Device installation and physical BLE/USB/RF acceptance are not
performed by the release process.
