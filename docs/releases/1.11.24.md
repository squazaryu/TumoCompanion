# TumoCompanion 1.11.24

- Protect the package-owned Device Library FAP, its cards/history and nested
  File History plugin from Community Pack replacement. Protection follows the
  canonical case-insensitive SD path, including renamed catalog entries.
- Reject Device Library installation on unknown/wrong firmware or Tumoflip F7
  below API 88.5. The check runs during compatibility review and again before
  writes. Other applications retain their existing requirements.
- Explicit Protected apps overrides remain available. No user files, cards,
  history or Bluetooth pairing data are deleted or migrated.

Install this companion update before FW Packages Dev 021. Automatic File History
also needs the corresponding runtime support from firmware Dev 009-009; passing
the minimum FAP API check alone does not enable automatic checkpoints.

The Bluetooth Remote controller repair is in **Tumoflip Dev 009-009**, not this
iOS patch. Existing Remote 1.3 from FW Packages remains compatible. A companion
update alone cannot repair peer selection on older firmware.

No breaking catalog/bridge schema changes. Hardware BLE acceptance is separate
from the policy tests, iOS build, and firmware release verification.
