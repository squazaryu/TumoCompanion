# TumoCompanion 1.12.0 — Field Kit

- **Home → Tools → Field Kit:** view exported object rounds and recording inventories on iPhone, compare two saved inventories, and export checked copies. Native difference logs without a completion footer remain explicitly unverified for completeness.
- **Sub-GHz profiles:** edit additional frequencies, hopping frequencies and ordinary presets. Review changes, retain custom/unknown settings, save a checked local original and write intent, verify the connected device and source bytes, then verify readback. Explicit recovery is available for interrupted writes.
- **Object cards:** create or edit portable `.tobj` packages with up to eight recording actions. Export to Files or stage a new package on Flipper, then explicitly import it in Field Tools as a **new** card with new payload copies. Installed card storage is not edited in place.
- **Recover one recording:** select a capture from a verified, manifest-backed backup and restore it to a new UUID file under the category's `Restored` folder. Original recordings are not overwritten or deleted.
- Protect checked edits from competing BLE mutations, including whole folder uploads and whole backup restores. Preserve accessibility text size in sheets and copy exact digests without visual hyphens.

## Update and use

Refresh the existing TumoCompanion source in Feather and install **1.12.0 (291)** using your own signing certificate. Do not add a duplicate source. No factory reset, BLE re-pairing, SD cleanup or path migration is required.

This app update reuses existing Tumoflip/Field Tools file formats and BLE RPC. **Tumoflip Dev011-001 and FW Packages Dev032 remain unchanged**; no new firmware or package release is required for these iPhone tools. Install the matching existing Field Tools package if it is not already present.

## Important limits

- Profile editing requires an existing `/ext/subghz/assets/setting_user`. Close Sub-GHz before applying and reopen afterward. Backups/recovery records are local to this iPhone and bound to the device and firmware identity.
- Portable-object editing creates a new package/card, not an in-place replacement. Selective capture recovery accepts supported recording roots and files up to 16 MiB; legacy manifestless ZIPs use the separate existing whole-archive restore flow.
- App-side exclusion is not a global SD lock or power-loss-atomic remote transaction. A failed new-copy transfer may leave a partial UUID copy; originals remain untouched. No automatic transmission, deletion or app execution is added.
- Functional source passed **723 unit and 29 UI tests** in CI, **5 additional UI scenarios on iOS 27.0**, native C format interoperability with ASan/UBSan, and **92.59% scoped field-logic line coverage**. Versioned-candidate build/check results are recorded separately during publication.
- Physical iPhone/BLE/Flipper acceptance remains pending. No attached Flipper is flashed or modified by publication. Independent code review was not performed.
