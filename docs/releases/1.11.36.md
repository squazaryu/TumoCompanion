# TumoCompanion 1.11.36 (289)

Fix Firmware channel navigation after the Stable010 promotion. No firmware or
FW Packages release is changed by this application patch.

## Cause and changes

- An installed Dev009-039 selects the Dev channel. With Stable010 newer than all
  Dev releases and on a different version line, the filtered Dev list is empty.
  The old view hid the drawer with that list, including the only channel picker.
- Keep the drawer available when the overall catalog has releases, even when
  the selected channel has none. Explain empty results without hiding navigation.
- Label the stable channel **Stable**, matching the user's release terminology.
- Keep explicit channel choices across installed-device identity refreshes;
  automatic channel detection remains the initial default until the user chooses.
- Cancel pending preparation on a channel change. Normal Release BLE/USB, backup,
  checksums and installer transaction guards are unchanged.

## Verification and scope

- Actual RED on iOS 27: two model and two light/dark UI tests reproduce the bugs
  before the fixes (checkpoint `6f0f16e`).
- GREEN: 705 unit tests and 17 update-source UI tests pass. The new tests exercise
  Dev → Stable010 → Dev → Stable, availability of preparation, and cancellation of
  the previous confirmation. Existing error/loading/preparation layouts still pass.
- Actual light/dark collapsed and expanded screenshots were inspected. Corrected
  model setters and drawer-availability getter have 100% measured line coverage;
  this is scoped coverage, not whole-application or physical-device acceptance.
- All existing host checks pass. CI now includes the firmware catalog/routing
  tests and both new empty-Dev UI routes.
- DEBUG-only fixtures model the installed Dev009-039 / new Stable010 case without
  a real BLE device or network. The fake transfer hook is compiled out of Release.

## Install and migration

Refresh the existing Feather source and update TumoCompanion in place. No reset,
SD cleanup, Bluetooth re-pairing, new source, firmware rebuild or data migration.
Then open **Firmware → Firmware releases → Stable → Version 010**. Keep backups
before installing firmware; install Stable010 with its resources before matching
FW Packages Stable007.

Physical installation and acceptance remain with the user. No connected Flipper
or SD card is written by the patch test/publication workflow. Temporary simulator
devices are task-owned and removed after preserving results.
